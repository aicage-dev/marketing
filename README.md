# aicage Marketing

Marketing strategy and content for [aicage](https://github.com/aicage/aicage) – the tool that runs AI coding agents in Docker containers.

## What is aicage?

```
pipx install aicage
aicage claude
```

Runs Claude, Codex, Gemini, Copilot, and 6 more agents inside Docker containers. Hard security boundary, same developer experience.
